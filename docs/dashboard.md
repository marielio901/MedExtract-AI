# Dashboard

O dashboard usa Jinja2, Bootstrap 5 e Chart.js.

## Indicadores

- total de documentos
- processados, pendentes e com erro
- pacientes unicos
- hospitais encontrados
- diagnosticos frequentes
- medicamentos frequentes
- confianca media da IA/extracao

## Graficos

- documentos por mes
- documentos por hospital
- diagnosticos frequentes
- medicamentos citados
- status de processamento

## Layout

O painel usa sidebar fixa, area central analitica e coluna direita de atividades recentes. O CSS e responsivo para desktop, tablet e mobile.
